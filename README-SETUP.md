# Prince Bonheur — Live Animated GitHub Profile

This bundle uses the **original exported GitSkins SVG artwork** as templates and refreshes the data every day with GitHub Actions.

## Trigger

- **Daily:** `23 5 * * *` — 05:23 UTC / **07:23 Rwanda time**
- **Manual:** GitHub → **Actions** → **Update Animated Profile** → **Run workflow**

## Live data

The generator refreshes profile counts, stars, contribution totals, active days, project cards/links, language stack, and the contribution-cell intensities. The SVG animation/visual layer stays intact.

## Install

Copy this bundle's contents into the `Ki-Will/Ki-Will` profile repository, commit, and push. GitHub's automatically provided `GITHUB_TOKEN` is enough; no personal access token is required.
